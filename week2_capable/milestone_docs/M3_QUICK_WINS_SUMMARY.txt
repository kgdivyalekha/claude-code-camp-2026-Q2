M3 — Quick Wins 🚀 PLANNING PHASE
================================================================================

GOAL: 5–15% token reduction with 1 day of focused work

THREE ORTHOGONAL OPTIMIZATIONS:

1. §3.1 — Parameter Requiredness (2 hours)
   Problem: All parameters marked "required" even when optional
   Impact:  5–7 false "required" per tool = 3–5% schema reduction
   Work:   Add Parameter.required field, mark optional params

2. §3.2 — Pair-Safe Compaction (3 hours)
   Problem: Context compaction breaks MUD conversations (agent gets lost)
   Impact:  Enables safe compaction = 5–10% reduction on long sessions
   Work:   Add LocationBookmark events, preserve across compaction

3. §3.3 — Trim Tool Descriptions (1 hour)
   Problem: Verbose descriptions + parameter echoes = ~1,500 extra tokens
   Impact:  Trim to 1 sentence max = 2–3% reduction
   Work:   Audit & trim all 26 tool descriptions

================================================================================
